# NeuroMirror — MVP v1 Scope

## Project Goal

NeuroMirror is a camera-based cognitive monitoring prototype designed
to repeatedly capture eye/gaze and facial behavioral features,
establish an individual longitudinal baseline, and identify changes
from a user's own historical patterns over time.

## MVP Modalities

Primary:
- Eye / gaze behavior

Supporting:
- Facial behavior

Interface only:
- Basic voice interaction

## Core Concept

Repeated Measurement
→ Personal Baseline
→ Longitudinal Change Detection

## Current Research Question

Can a camera-based system reliably capture eye/gaze behavioral
features across repeated sessions and establish a stable individual
longitudinal baseline?

## Out of Scope for MVP v1

NeuroMirror v1 does not:
- diagnose Alzheimer's disease
- diagnose MCI
- calculate Alzheimer's risk
- provide medical treatment recommendations
- replace clinical cognitive assessments
- use speech as a cognitive biomarker
- provide clinical decision support
